## What ships for 13F

Code only, plus one manual command. **Nothing is stored, scheduled or scored.**

- `lib/zip-stream.js`: streams a large ZIP entry line by line (no dependency, no unpacking).
- `lib/thirteen-f-stream.js`: SEC date normalization (DD-MON-YYYY), amendments from
  `COVERPAGE.tsv` (restatements replace, new-holdings amendments add), per-report-period
  aggregation across filing-window files, data-set file listing.
- `lib/cusip-map.js` (rewritten): CUSIP → ticker through OpenFIGI (`OPENFIGI_API_KEY` if set),
  cross-checked with the SEC fails-to-deliver files; disagreements stay unmapped.
- `node jobs/thirteen-f-ingest.js dry-run`: the Phase 0 checks in one command.

## The OpenFIGI key (when Sam C sends it)

Add to the shared `.env` on the Jetson (never print it, never commit it):

```
OPENFIGI_API_KEY=<key>
```

The dry run works without it, just with slower OpenFIGI limits (about a minute longer).

## Run the dry run

After the deploy (or from the merged checkout; it does not need a restart):

```bash
cd ~/portfolio-manager
node jobs/thirteen-f-ingest.js dry-run > /tmp/13f-dry-run.json; tail -c 4000 /tmp/13f-dry-run.json
```

Expect a few minutes. It downloads one SEC data-set ZIP (tens of MB) and two fails-to-deliver
files to a temporary folder and deletes them at the end. Send Sam C the whole JSON file. The
key fields: `status`, `dataSetFiles`, `headers`, `filings`, `holdings.periods`, `mapping`,
`samples` (ownership % for AAPL, MSFT, NVDA, ...), `cost` (seconds, peak memory), `problems`.

`status: "failed"` with an `error` naming missing columns is a useful result, not a breakage:
it means the real file differs from what the parser expects, which is exactly what this run
is for. Do not change code to work around it; send the output.
